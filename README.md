# Production Grade Full-Stack Projects 🚀

This repository contains multiple production-style full-stack applications built using modern web technologies.

The goal of this repository is to demonstrate experience designing, building, and shipping scalable applications using a professional technology stack.

## Tech Stack

Frontend
- React
- TypeScript
- Modern CSS / UI Libraries

Backend
- Node.js
- Express.js
- REST APIs

Database
- PostgreSQL
- Relational data modeling
- SQL queries and indexing

Other Tools
- Git & GitHub
- Axios / Fetch
- Docker (for some projects)
- Environment variables
- Production-ready folder structures
